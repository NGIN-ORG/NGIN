# NGIN.Base Foundation API

**Foundation include:** `<NGIN/NGIN.hpp>`  
**Target:** `NGIN::Base::Foundation`

The foundation umbrella does not include Async, Execution, I/O, Networking,
Serialization, or Crypto. Prefer focused umbrellas in public headers.

| Area | Include | Reference |
| --- | --- | --- |
| Scalars and platform | `<NGIN/Primitives.hpp>`, `<NGIN/Defines.hpp>` | [Primitives and platform](./foundation/primitives-platform.md) |
| Results and exceptions | `<NGIN/Utilities.hpp>`, `<NGIN/Exceptions.hpp>` | [Results and exceptions](./results.md) |
| Metadata and hashing | `<NGIN/Meta.hpp>`, `<NGIN/Hashing.hpp>` | [Meta and hashing](./meta-hashing.md) |
| General utilities | `<NGIN/Utilities.hpp>` | [Utilities](./utilities.md) |
| Text and Unicode | `<NGIN/Text.hpp>` | [Text](./text.md) |
| Math and units | `<NGIN/Math.hpp>`, `<NGIN/Units.hpp>` | [Math and units](./math-units.md) |
| Monotonic time | `<NGIN/Time.hpp>` | [Time](./time.md) |
| Vectorized operations | `<NGIN/SIMD.hpp>` | [SIMD](./simd.md) |

Memory/containers have their own [reference index](./memory-containers.md).
